? How the research assistant works ⌄
  1. Understand: Gemini identifies your topic and priorities, asking a focused follow-up when needed. A basic rule parser is used if Gemini is unavailable.
  2. Check locally: It checks for a complete saved preview in the local database.
  3. Discover: If local coverage is insufficient, it requests more metadata from OpenAlex.
  4. Validate and save: It checks and stores records with their source identifiers.
  5. Explain: When asked, it uses available abstracts and checks supporting citation excerpts. Dates filter publication time; retrieval time is shown separately.
