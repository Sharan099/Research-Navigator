# Research Navigator

Explore publication metadata from OpenAlex, keep topic conversations and inspect available abstracts.

[Source code and documentation](https://github.com/Sharan099/Research-Navigator)

This is a prototype demo. Storage may be temporary, provider allowances are shared, and browser
cookies control access to conversations. Abstract quote checks do not establish scientific accuracy.
